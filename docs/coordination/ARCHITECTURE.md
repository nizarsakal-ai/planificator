# Architecture vérifiée

Le navigateur Next.js appelle les routes privées V3 ; session, origine et droits sont contrôlés avant lecture des corps puis relus dans les transactions. Prisma utilise Neon. La production conserve sa branche d’origine br-restless-king-al1y1sqf et son endpoint ep-plain-voice-alhstww7. La préproduction est un autre projet/base, via V3_STAGING_DATABASE_URL.

Les sources et documents sont privés et versionnés chez Cloudinary. OCR Anthropic soumis au consentement et aux quotas. IGN propose les coordonnées ; leur confirmation reste humaine. GraphHopper11.1 calcule des estimations voiture sur le graphe France versionné ; caches/quotas sont persistants, secrets exclusivement serveur. Le routage ne garantit pas les contraintes poids lourds.

Les tournées réservent les ressources et utilisent le journal V2 pour leurs compteurs réels. Une étape a un résultat effectué ou non visité avec motif/auteur/date, jamais les deux. Une seule migration additive ajoute ce dernier résultat. Les historiques SQL déjà appliqués ne sont pas réécrits.

Le contrôleur de coordination VPS est distinct du Raspberry. Son exécution est limitée au dépôt test et n’est pas utilisée pour publier V3. La publication Vercel est effectuée directement par Codex dans le périmètre autorisé.
